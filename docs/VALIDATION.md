# 迁移与验收记录

记录日期：2026-10-22。以下区分离线回归、实时网络和阅读真机结果，不把不同口径混合。

## 迁移回归

原 Python 测试集：269 项，268 通过、1 跳过、0 失败。导出的可比较契约中，Rust 当前运行 14,109 次调用，覆盖 126 个辅助操作、187 个原测试方法，全部通过。它们作为一个聚合回归测试运行，不能称为“14,109 个独立测试”或“原 269 项逐项原样移植”。

当前 Rust 普通回归为 52 项通过，另有 1 个默认忽略的手动编译性能测量入口。

| 原实现范围 | Rust 对照方式 |
| --- | --- |
| 静态常量、数据结构、公式、几何、样式、声明环境、标量、编解码 | 录制的纯数据契约，调用实际运行路径的辅助函数；保留独立 wire 向量和大包摘要 |
| HTTP、压缩、重定向、鉴权、原始状态、完整取页 | 本地上游与 Axum 集成测试，不依赖真实网站 |
| DNS 单飞、到期、失败恢复、CDN 地址映射、有限回退 | network 原生异步测试，注入本地 DoH 与上游 |
| 会话隔离、读写锁、32 个会话、取消和统计 | service 与 HTTP 原生测试，包括验证取消后不能遗留已验证状态 |
| Cookie 范围及导出不改变会话 | 原生 Cookie 测试，覆盖 host-only、domain、path、secure、expiry |
| 回调、手动时钟、自检、直接完成与未知后续 | native_regression，使用显式时钟和注入依赖 |
| 原 Python ABI、标量回退、解析器缓存内部接口 | 旧架构接口不进入 Rust 服务；以新实现独立向量、真实计算和节点遍历边界测试替代 |
| 旧人工校准路径 | 不进入严格原生验收，也不进入交付运行路径 |
| Android 日志/站点稳定性/报告生成等开发工具 | 旧工具保留本地，不将这些 Python 工具伪装成 Rust 运行功能 |

差异比较显式处理动态时间和无序集合；数值比较允许 1e-12 相对误差，协议字符串仍精确比较。已知数学字段中的超越函数结果受 Windows CRT / Linux libm 末位舍入影响，限定允许最多 4 ULP；整数运算、精确函数、特殊值、数字文本格式与其他字符串不放宽。这一测试差异不修改运行时计算，可参见 [Rust f64 精度说明](https://doc.rust-lang.org/std/primitive.f64.html#method.acosh)。工作量结果验证哈希与边界，时间指标验证非负和结构，不固定一次测量的耗时。独立数据 fixture 不含 Cookie、服务令牌、代理密码或开发者局域网地址。

## 核心优化

同一份真实初始化程序的 debug 编译分析由约 6.73 秒降为约 2.77 秒：树节点只遍历并索引一次；子树查询复用节点区间；先验证简单约束再做昂贵查询；密钥相关扫描限定为当轮已识别的名称长度。索引遍历与原遍历在所有测试子树、两种嵌套函数策略下完全一致。该数字是编译分析时间，不能冒充整次网络访问时间。

随后使用优化 release 构建，执行 5 个独立冷进程、全新会话取页，不添加页面缓存、不用自动重试替换慢样本：

| 目标 | 墙钟总耗时 | 原生分析耗时 | 实际结果 |
| --- | ---: | ---: | --- |
| linux.do/challenge | 3.859 s | 696 ms | 真实 LINUX DO 404 页面，严格验收通过 |
| linux.do/challenge | 4.180 s | 748 ms | 同上 |
| linux.do/challenge | 4.227 s | 767 ms | 同上 |
| twkan.com | 4.867 s | 692 ms | 实际网站 200 页面，严格验收通过 |
| twkan.com | 4.876 s | 770 ms | 同上 |

五次均未复用编译布局。范围 3.86～4.88 秒，仅代表这五次网络条件下的有限样本。先前一次未优化冷进程为 6.007 秒，因此优化依据包含慢样本，而非只挑选成功的短请求。

## 配套书源真机

设备序列号尾部 tous，使用 USB 接入；不操作其他设备。阅读真实调试流水线通过：

| 示例 | 搜索或入口 | 实际目录 | 正文 |
| --- | --- | ---: | ---: |
| 台湾小说网 | 简体“川菜馆” | 727 章 | 首章 3,312 字符 |
| 半夏小说 | 简体“嫁给残疾” | 504 章 | 首章 2,284 字符 |
| 69书吧 | 完整书籍链接 | 569 条实际章节链接 | 正文非空且已检查解析；目录改为 data-num 升序 |

发现页共检查台湾小说网 18 个标签、半夏 13 个、69书吧 20 个，逐个执行第一页和第二页，输出名称经阅读内置 t2s 转为简体。半夏 12 个分类的前两页均返回 30 条且无交集。台湾的分类/完本页为 15 条、榜单为 30 条；部分分类相邻页重叠，独立比对原始上游 HTML 确认网站本身存在重叠。69书吧本次页面不提供下一页导航，示例正常结束，不凭空制造分页。

封面补查发现台湾小说网和半夏直连返回 403。增加二进制 /image 代取后，三站封面均在真机返回 200 / image/jpeg；接口共用验证会话，检查图片签名，并拒绝 HTML 和 SVG，压缩图片以解压后的原始字节返回。

69书吧的关键词搜索未通过独立嵌入式验证，因此没有标为支持。其入口、Web 卡片与源说明都明确采用“发现与链接取书”范围。HTTP 200 的验证提示页不能算搜索成功。台湾与半夏为完整搜索示例。

## Web 与容器

Web 由提供的蓝橙图标改为中性底色与蓝色操作区，支持系统暗色及手动切换。后端测试覆盖历史上限、可复现请求参数、来源导出令牌范围、无令牌拒绝以及三站点导出。

Docker CI 在两个原生架构 runner 上运行同一离线回归，并启动实际镜像，用有令牌和无令牌两轮测试 Web、图标、三份书源、页面代取、原始 404、内存统计、二进制图片代取和请求历史。通过后才发布架构镜像并合并清单。运行结果以该提交的 GitHub Actions 记录为准；文档不将本地 Windows 二进制测试冒充容器测试。
