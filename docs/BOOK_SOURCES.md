# 编写接入示例

服务返回页面，书源负责解析。正式示例统一代取，不把服务签发的 Cookie 假定为可以在不同出口的客户端直接使用。

## 文件

sources.rs 验证服务地址并输出 config、站点标识、服务地址、服务令牌，再拼接 gateway-source.js 与站点 parser。/sources.json 返回三份完整书源对象的 JSON 数组，各自 mainJs 包含同一套动态脚本；Web 的导入、复制和下载均使用此批量接口，在阅读的同一个窗口选择或更新。/source.js 保留单份脚本兼容入口，不维护另一套生成后的书源文件。

gateway-source.js 包含请求、会话、同站 URL 解析、简繁转换辅助和从网页提取发现分类的逻辑。每个 parser 提供：

```js
function search(key, page) { /* 返回书籍数组 */ }
function explore(url, page) { /* 返回书籍数组 */ }
function getBookInfo(book) { /* 返回书籍详情 */ }
function getChapters(book) { /* 返回章节数组 */ }
function getContent(chapter, book, nextChapterUrl) { /* 返回正文 */ }
```

当前示例使用此仓库阅读应用支持的 JS 单文件书源格式，不能假定所有旧版阅读均支持这组回调。

## 请求

cfRead 使用阅读的 java.connect 请求服务端 /fetch，并在 Authorization 请求头携带令牌。目标 URL 作为 url 参数传入，固定 session 保持会话。代理不由示例隐式配置。书源请求的服务总时限为 45 秒，阅读调用总时限为 55 秒，均先于阅读默认 60 秒读取时限结束。cfRead 还检查 text/html，防止 connect 将网络异常包装成 200 文本后误解析为空列表。封面请求同样携带 45 秒服务时限。

会话标识格式为 `legado-站点标识-时间戳-随机后缀`，站点标识分别为 twkan、69shuba、banxia。台湾小说网旧版保存的 `legado-relay-…` 会在更新后首次使用时改为 `legado-twkan-…`，保留唯一后缀与翻页状态，不改其他站点或用户自定义标识。标识改变后服务按新名称建立会话，旧的内存会话自然淘汰。

cfUrl 使用 Java URI 解析相对地址，并限制为示例站点，保持路径与查询的原始编码。书名、作者、正文做简繁转换，不能转换 URL 或已经编码的请求字节。封面通过 cfCover 包装为服务 /image 地址，保留原始上游图片 URL 作为参数。cfCover 必须先检测已包装的服务地址，再将原始上游 HTTP 地址规范为 HTTPS，否则本地 HTTP 服务会被误改并二次包装，导致封面 502。图片复用相同会话，避免阅读的图片加载器直连遇到 403。带令牌时使用只读图片接口的 token 参数；不能把服务令牌转发给上游。

## 简繁转换

繁体站点的搜索使用 String(java.s2t(String(key)))；输出使用 String(java.t2s(text))。不要添加一份自己的简繁字典。Java 方法返回的 String 在 Rhino 中可能是 Java 对象，对它调用 JavaScript 正则 replace 前须先使用 String(...)，避免 Java 重载选择错误。

## 发现与翻页

cfDiscovery 从站点分类和榜单页面提取名称及链接，仅固定少量导航入口。配置 exploreUrl 调用这段逻辑，由阅读管理发现标签的加载。修改标签后应重新导入书源并刷新发现分类。

cfDiscoveryLayout 只处理排版：首页入口独占一行，其余入口、分类和榜单使用等宽三列，分类与榜单各自分组。不改站点返回的名称与链接；末行不足三项时保持列宽，不拉伸单个按钮。分组标题没有 URL，不触发取页。宽度比例为阅读原生 FlexChildStyle 的小数值，并为按钮边距和列间隔留出空间。

cfExplore 保存下一页导航地址，不保存 HTML。仅跟随实际页面的下一页链接，页面无下一页就返回空数组。页面 1 会重置该栏目的导航状态；不同栏目隔离，最多保存 24 组导航。不要对所有 URL 一律拼接 ?page=2，也不要让不分页的首页无限重复。

部分站点本身的相邻分类页会重叠。检查时同时对照原始上游页面，不能误认为服务响应缓存。目录必须使用完整目录接口；保持实际章节顺序，69书吧根据 data-num 升序排列。书籍详情中的章节数可能和实际目录不同，以实际目录条目为准，不伪造缺失章节。

## 验收清单

封面严格取自当前页面的 img、懒加载属性或详情页元数据，不根据书籍 ID 拼接图片地址。列表没有封面时返回空值，详情页有封面才显示详情页提供的地址；不为补图批量请求每本书的详情页。69书吧部分详情页自身只提供默认 nc.jpg，占位图不代表有原书封面。

- 用简体输入搜索，核对书名、作者、简介、封面与详情链接。
- 对所有发现标签检查第一页；有下一页的栏目继续请求，确认请求 URL 实际变化。
- 核对目录首尾章节、顺序、数量以及重复 URL。
- 检查正文首尾，不以“正文非空”代替末段完整性。台湾小说网的 canvas 末段需要正确还原，未知编码应报错。
- 在指定真机的阅读内执行实际回调，不能只在 Node 中通过语法检查就宣称可用。
- 令牌模式与无令牌模式都验证导出，服务地址包含自定义端口和 HTTPS。

69书吧的站内关键词搜索使用 `URLEncoder.encode(keyword, 'GBK')`，逻辑地址由 Rust 按网站表单转换为 POST。服务识别搜索页的独立 Turnstile，计算当前任务、提交令牌至同站 `/verify.php`，保存站点返回的 Cookie，并重新提交原搜索。组件没有传入的 action/cData/chlPageData 不能用整页挑战的参数代替。完成消息中的 token 与 sToken 不能按字符串格式混选。

搜索结果 `.newbox > ul > li` 需解析书名、作者、分类、简介、最新章节与封面，不能只抓所有链接。搜索结果为零时返回空数组；网站要求两次搜索间隔不少于 5 秒时抛出原始提示。页面未给出下一页链接时结束，不重复搜索制造分页。HTTP 200 的验证提示页仍不能算搜索结果。嵌入式适配目前只覆盖69书吧已验证的声明，不声称支持任意站点回调。

## 简介与首页字段

cfIntro 对简介中的转义 HTML 与字面标签做最多三轮解析，保留分段、删除脚本样式、独立省略号行及带明确群号的独立推广行，保留正常书名别名说明。只在简介字段使用，不修改 URL 或正文。

三站首页卡片并未提供简介，69首页榜单还缺少作者。保持上游真实字段，不为补齐列表额外逐本请求详情，避免放大发现页耗时。69封面可按该站真实 CDN 图片路径与书籍 ID 取得；实际返回失败仍交给阅读默认封面处理，不能伪造作者或简介。

## 台湾小说网正文净化

台湾小说网在简繁转换后调用 cfCleanTwkanContent。正文段落只要包含“台湾小说网”就整段删除，兼容台／臺、湾／灣、说／說、网／網及穿插空白、零宽字符；不依赖随机宣传文案、域名字体、前后缀或长度。未带站名的已知搜索引流和变形域名水印继续按原文 UTF-16 位置删除对应片段，检测副本的 Unicode 兼容分解不改写其余正文。

随机水印按“固定域名＋Unicode 字形替换＋装饰边框”处理，兼容方框字母、上标、混合脚本同形字、拆字括号和穿插空白；不枚举完整随机广告。两侧装饰随已识别域名一起清除，空域名的双表情／双全角空格边框也按同一生成形状处理。夹引号的收藏提示按其推广标记识别，不依赖已经损坏的网址。

日常阅读不会调用 AI。单独数字、短字母、普通表情和原站已有错字不按形式猜删。规则修改后重新联网拉取 100 章完整正文，按当前规则净化，再由 AI 全文检查残留和误删；未通过则修改后另拉一批，不使用旧正文充当新验收。旧样本仅用于回归。运行 node tests/twkan-cleanup.cjs，并在阅读真实环境执行生产正文回调。

## 全文净化与重复标题

三份示例在正文输出前调用 cfCleanChapterText，按目录标题、页面 h1 和书名匹配独立章首抬头。比较兼容额外列表编号、重复或缺失章号、不同内部计数、全半角、引号、省略号及标题中的字数／加更附注，容忍元数据在末尾括号内被截短；原文只移除确认等价的标题行，普通叙事中的同名词句保留。已有外部标题仍负责显示章名及其附注，独立作者感言与字数说明保留。

水印、站点提示和控制字符的检查覆盖完整正文。半夏处理已确认的独立站点口号、两段损坏导航提示及重复 nbsp 实体残留；三源去掉不可见控制字符而保留两侧文字，剥离独立或结尾的本章完标记。台湾额外清理本轮明确确认的装饰串与独立尾部 HTML 符号，不对普通表情、数字或错字做全局猜测删除。专项回归为 node tests/content-cleanup.cjs；全文 AI 只参与离线规则开发，不进入正常阅读请求。

69书吧正文移除每段开头的空白，包括网页 EM SPACE、全角空格、不换行空格与普通空格、制表符，避免叠加阅读自身的首行缩进；段内空格和段落边界保留。
